# Changelog

## 0.1.0

Initial release:

- Transactional SQLite document storage with FTS5 BM25 indexing.
- Exact cosine retrieval over caller-supplied normalized float32 vectors.
- Namespace and flat metadata filtering before candidate truncation.
- Explainable weighted reciprocal rank fusion and deterministic ties.
- Explicit ingestion/query model labels and vector/input bounds.
- JSONL ingestion, search, deletion, statistics and report commands.
- Static HTML comparison reports with revision checks and escaped content.
- An explicitly labeled toy-vector demo and provider-independent integration example.
